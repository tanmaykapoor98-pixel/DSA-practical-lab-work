DATA STRUCTURES LAB RECORD - NON-SORTING C++ PROGRAMS

This folder contains separate .cpp files for the non-sorting programs in the supplied index.
Sorting programs previously requested are intentionally excluded.

Compile a file with:
    g++ filename.cpp -std=c++17 -o program
Run:
    ./program
On Windows:
    program.exe

Notes:
- Each file is a standalone program.
- For BT.cpp and AVL_or_not.cpp, enter -1 for a missing child.
- In BT.cpp, enter the root first; then enter left and right children level by level as prompted.
- kthSmallestLL.cpp uses sorting internally to determine the kth-smallest value, but it is the linked-list kth-smallest exercise, not a sorting-algorithm lab file.
